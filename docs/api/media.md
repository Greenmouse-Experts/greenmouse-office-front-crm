# Multimedia & Cloud Storage API

Direct asset uploads to Cloudinary for logos, avatars, PDFs, receipts, and media attachments.

## Overview & Quick Reference

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | [`/v1/multimedia/upload`](#upload-a-file-image-video-or-pdf-to-cloudinary) | Upload a file (image, video, or PDF) to Cloudinary |

---

## Endpoints

### Upload a file (image, video, or PDF) to Cloudinary

`POST /v1/multimedia/upload`

**Responses**

#### `201 Created`
